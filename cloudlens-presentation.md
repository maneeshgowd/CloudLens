## SLIDE 2 — The Problem

**Your cloud environment grows silently broken.**

AWS gives you tools — but they're siloed:
- Trusted Advisor → cost waste
- Security Hub → vulnerability findings
- Compute Optimizer → sizing recommendations
- CloudWatch → metrics you've already configured alarms for

**What falls through the gaps:**

| Scenario | What AWS tells you | Reality |
|---|---|---|
| EventBridge + Lambda pipeline breaks | Nothing | Zero events flowing, no alarm fired, broken for 14 days |
| Lambda on Node.js 18 (EOL Sep 2025) | Separate Security Hub finding | Unpatched CVEs accumulating in production right now |
| Function deployed 18 months, never invoked | Trusted Advisor: "idle" | Dead code holding live IAM permissions |

**Speaker note:** *"The status quo is: you find out when a customer reports it, or when you fail a security audit."*

---

## SLIDE 3 — What CloudLens Does

**One command. Full picture.**

```
node cloudlens.js --provider aws --region us-east-1 --days 7
```

- Scans **13 AWS services** + Azure in a single read-only pass
- Correlates findings **across services** (the thing AWS doesn't do)
- Generates an **AI executive briefing** — plain English, no jargon
- Outputs a **self-contained HTML report** with actionable fix commands

**Services covered (AWS):** Lambda · EventBridge · DynamoDB · SQS · SNS · S3 · API Gateway · ECS · NAT Gateway · Provisioned Concurrency · Secrets Manager · CloudFront · MSK

**Speaker note:** *"It's read-only — zero risk to run in production. No agents, no persistent infrastructure, no IAM role changes needed beyond read access."*

## SLIDE 4 — The Differentiator

**Cross-service pipeline correlation — this is what's unique.**

> *"Trusted Advisor tells you a Lambda function is idle.*
> *CloudLens tells you the automated pipeline behind it is broken — the EventBridge rule is enabled, scheduled, and firing — but zero events are reaching the function. No alarm has fired. This is a broken workflow your monitoring didn't catch."*

**CloudLens uniquely surfaces:**

1. **Silent pipeline failures** — EventBridge + Lambda correlation, flagged as `PIPELINE_SILENT`
2. **Security exposure** — EOL runtimes with specific CVE risk, dead code with live IAM permissions
3. **AI Risk Briefing** — 3–4 sentences a CTO can read in 10 seconds, generated by Claude after every scan
4. **Actionable fix commands** — every finding includes a ready-to-run AWS CLI command

**Speaker note:** *"No single AWS console, and no competing tool we found, does the cross-service correlation automatically. That's the gap."*

## KEY MESSAGES (for Q&A)

**"Why not just use Trusted Advisor?"**
> "Trusted Advisor tells you a Lambda is idle. CloudLens tells you the pipeline behind it is broken — rule is active, schedule is set, nothing is moving, no alarm fired. That's a different class of finding."

**"How is this different from Security Hub?"**
> "Security Hub tracks known CVEs and config rules. CloudLens surfaces operational failures — broken workflows, dead code with live permissions, EOL runtimes — from live CloudWatch data, in a single cross-service view."

**"Can it scale?"**
> "It's stateless and read-only. Add `--filter` to scope to a team or service. The natural next step is GitHub Actions — weekly run, report committed, delta tracked automatically across the org's accounts."

**"What's the cost to run?"**
> "CloudWatch API calls and a few SNS/Lambda list calls — under $0.10 per full scan of a medium AWS account. The AI briefing adds a few cents via the Claude API."
